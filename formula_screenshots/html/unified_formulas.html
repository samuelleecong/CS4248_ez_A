Knowledge Distillation Loss Functions

Teacher: all-MiniLM-L6-v2 (frozen) → Student: TinyBERT-4L (trainable) on MBPP

Notation

$$\mathbf{S}_q,\; \mathbf{S}_d$$ Student query / document embeddings
$$\mathbf{T}_q,\; \mathbf{T}_d$$ Teacher query / document embeddings
$$s^s_{ij},\; s^t_{ij}$$ Student / teacher similarity scores
$$B$$ Batch size (in-batch negatives)
$$\tau,\; \tau_d$$ Temperature for CE / distillation
$$\lambda_d,\; \lambda_a,\; \lambda_p$$ Loss weights (distill / align / pairwise)
$$\sigma(\cdot)$$ Sigmoid function
$$\|\cdot\|_2$$ L2 (Euclidean) norm

Shared Base Losses

Contrastive Cross-Entropy Loss
Trains the student to rank the positive document highest among in-batch negatives.
$$\mathcal{L}_{CE} = -\frac{1}{B}\sum_{i=1}^{B} \log \frac{\exp(s_{ii}/\tau)}{\sum_{j}\exp(s_{ij}/\tau)}$$
Score Distribution Distillation
Transfers knowledge by training the student to match the teacher's output probability distribution (soft labels), capturing nuanced inter-document relationships.
$$\mathcal{L}_{KL} = \mathrm{KL}\!\left(\mathrm{softmax}\!\left(\frac{\mathbf{S}_s}{\tau_d}\right) \;\Big\|\; \mathrm{softmax}\!\left(\frac{\mathbf{S}_t}{\tau_d}\right)\right) \cdot \tau_d^{\,2}$$
Method Variants
1. Supervised Baseline
No teacher signal. Student learns from labeled pairs only using contrastive retrieval.
$$\mathcal{L} = \mathcal{L}_{CE}$$
2. Score Distillation
Transfers knowledge by training the student to match the teacher's output probability distribution (soft labels), capturing nuanced class relationships.
Cross-encoder scoring: student queries scored against teacher documents
$$\mathbf{S}_s = \mathbf{S}_q \cdot \mathbf{T}_d^\top \qquad \mathbf{S}_t = \mathbf{T}_q \cdot \mathbf{T}_d^\top$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_d \,\mathcal{L}_{KL}$$
3. Embedding Distillation
Aligns the internal feature representations of the student with those of the teacher, encouraging similar understanding at intermediate layers.
$$\mathcal{L}_{align} = \frac{1}{B}\sum_{i=1}^{B} \left\|\mathbf{S}_{q_i} - \mathbf{T}_{q_i}\right\|_2$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_d \,\mathcal{L}_{KL} + \lambda_a \,\mathcal{L}_{align}$$
4. Hard-Negative Pairwise Distillation
Preserves relational knowledge by teaching the student to mimic pairwise relationships or similarities between data samples learned by the teacher.
$$\mathcal{L}_{pair} = \frac{1}{|M|}\sum_{(i,j)\in M} \mathrm{BCE}\!\left(\sigma\!\left(\frac{s^s_{ii} - s^s_{ij}}{\tau_d}\right),\; \sigma\!\left(\frac{s^t_{ii} - s^t_{ij}}{\tau_d}\right)\right)$$
$$M = \{(i,j) : j \in \text{top-}k\text{ hardest negatives for query } i\}$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_d \,\mathcal{L}_{KL} + \lambda_p \,\mathcal{L}_{pair}$$
5. Query Embedding Alignment (QED)
Direct query-only L2 alignment without score distillation. The simplest embedding alignment baseline.
$$\mathcal{L}_{align} = \frac{1}{B}\sum_{i=1}^{B} \left\|\mathbf{S}_{q_i} - \mathbf{T}_{q_i}\right\|_2$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_a \,\mathcal{L}_{align}$$
6. Margin MSE
Preserves pairwise ranking margins by minimizing the squared difference between student and teacher score margins across all document pairs.
$$m^s_{ij} = s^s_{ii} - s^s_{ij} \qquad m^t_{ij} = s^t_{ii} - s^t_{ij}$$
$$\mathcal{L}_{mse} = \frac{1}{|M|}\sum_{\substack{i,j \\ i \neq j}} \left(m^s_{ij} - m^t_{ij}\right)^2$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_p \,\mathcal{L}_{mse}$$
7. BiMGA -- Bidirectional Margin-Guided Alignment (Ours)
Improves student learning by aligning both query and document representations bidirectionally, weighted by teacher confidence margins -- capturing richer structural and semantic information.
Margin-based confidence weighting: high-confidence pairs receive stronger alignment
$$m_i = s^t_{ii} - \max_{j \neq i}\, s^t_{ij} \qquad w_i = \sigma\!\left(\frac{m_i}{\tau_d}\right)$$
$$\mathcal{L}_{align} = \frac{1}{B}\sum_{i=1}^{B} w_i \left(\left\|\mathbf{S}_{q_i} - \mathbf{T}_{q_i}\right\|_2 + \left\|\mathbf{S}_{d_i} - \mathbf{T}_{d_i}\right\|_2\right)$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_d \,\mathcal{L}_{KL} + \lambda_a \,\mathcal{L}_{align}$$
8. BiMGA Uniform (Ablation)
Ablation of BiMGA with uniform weighting (w_i = 1) to isolate the effect of margin-guided confidence weighting.
$$\mathcal{L}_{align} = \frac{1}{B}\sum_{i=1}^{B} \left(\left\|\mathbf{S}_{q_i} - \mathbf{T}_{q_i}\right\|_2 + \left\|\mathbf{S}_{d_i} - \mathbf{T}_{d_i}\right\|_2\right)$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_d \,\mathcal{L}_{KL} + \lambda_a \,\mathcal{L}_{align}$$
9. ADAM-Lite -- Dark Example Distillation
Generates synthetic hard negatives ("dark examples") by interpolating positive and negative document embeddings, then distills over these augmented examples weighted by teacher confidence.
$$\tilde{\mathbf{d}}_k = \mathrm{normalize}\!\left(\alpha\,\mathbf{d}^{+} + (1-\alpha)\,\mathbf{d}^{-}_k\right)$$
Confidence gate: teacher certainty modulates dark-example loss strength
$$c_i = \sigma\!\left(\frac{s^t_{i,+} - \overline{s^t_{i,\mathrm{dark}}}}{\tau_d}\right)$$
$$\mathcal{L}_{dark} = \frac{1}{B}\sum_{i=1}^{B} c_i \cdot \mathrm{KL}\!\left(\mathrm{softmax}\!\left(\frac{\tilde{\mathbf{S}}^s_i}{\tau_d}\right) \;\Big\|\; \mathrm{softmax}\!\left(\frac{\tilde{\mathbf{S}}^t_i}{\tau_d}\right)\right) \cdot \tau_d^{\,2}$$
$$\mathcal{L} = \mathcal{L}_{CE} + \lambda_d \left(\mathcal{L}_{KL} + \mathcal{L}_{dark}\right)$$

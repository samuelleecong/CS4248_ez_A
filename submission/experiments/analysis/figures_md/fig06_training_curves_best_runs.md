# Figure 6: Training curves for representative runs

**Purpose:** Show whether the best methods improve steadily or only late in training.

![Figure 6: Training curves for representative runs](../figures/fig06_training_curves_best_runs.png)

## How to read this
Each line is validation MRR across epochs for one representative run.

## What it shows
The strongest final validation curve in the representative subset is s3_A2_bimga_uniform with final validation MRR 0.4838.

## Why it matters for the paper
This helps separate stable improvements from lucky endpoint results.

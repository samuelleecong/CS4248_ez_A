Cluster-Based Routing for Knowledge Distillation Student Ensembles

Supplementary figures for Section 5.4: Routing Analysis

1Motivation

Knowledge distillation methods transfer different types of teacher signal to the student: score-level ranking (score_distill), embedding geometry (embed_distill), pairwise preference (hard_neg_pair), and bidirectional alignment (BiMGA). A natural question is whether these methods are complementary — i.e., whether they succeed on different subsets of queries — and if so, whether we can exploit this complementarity at inference time.

We investigate two ensemble strategies: (1) model merging, which averages model weights at different interpolation ratios, and (2) cluster-based routing, which assigns each query to the best-performing student based on the query's embedding cluster. All experiments use the 30-epoch models from Set 1 (TinyBERT-4L student, MiniLM-L6-v2 teacher, TACO dataset, symmetric evaluation).

2Model Merging

We evaluate linear weight interpolation between all pairs of the five trained students at ratios α ∈ {0.0, 0.25, 0.5, 0.75, 1.0}, yielding 25 merged models. The merged model weights are computed as (1-α)·WA + α·WB.

The best merge achieves MRR = 0.2980 (BiMGA 75% + hard_neg_pair 25%), which is only +0.0007 above BiMGA alone (0.2973). All merges at α = 0.5 underperform both parent models, and the benefit decreases monotonically as the weaker model's contribution increases. We conclude that weight-space averaging is ineffective for these models — their learned representations occupy sufficiently different regions of parameter space that interpolation degrades both.

3Cluster-Based Routing

We cluster validation queries using k-means on fine-tuned teacher query embeddings, evaluate each student's MRR on each cluster, and build a routing dictionary mapping clusters to students. At test time, each query is assigned to its nearest cluster centroid and routed to the corresponding student.

We evaluate two routing strategies:

Hard routing. Each query is scored by the single best student for its cluster. This is equivalent to a mixture of experts with non-overlapping assignment.

Soft routing. Each query's retrieval score is a weighted combination of all students' scores, where the weights are proportional to each student's validation MRR on that cluster: s(q, d) = Σm wm,c(q) · sm(q, d), with weights normalized to sum to 1.

5Discussion

The routing analysis reveals three findings relevant to the broader study of knowledge distillation for retrieval:

KD methods are complementary, not redundant. The oracle MRR of 0.381 versus the best single-model MRR of 0.298 represents a +28% relative improvement. This gap is not explained by random variation — it reflects systematic differences in which queries each method handles well. Score-based KD (score_distill) dominates on "easy" clusters where relative ranking information suffices (C3), while embedding alignment methods (bimga, bimga_uniform) are preferred on harder clusters where geometric proximity to the teacher embedding space matters (C0, C2, C5, C7).

Soft routing is robust; hard routing is not. Soft routing achieves consistent gains (+0.012 MRR) across all values of k, because the weighted score combination preserves information from all models even when the cluster assignment is imperfect. Hard routing, by contrast, degenerates at low k (all clusters select the same model) and suffers from cluster boundary errors at high k. This suggests that for practical deployment, soft routing with a small k (4–8) is preferred.

Weight averaging fails where score averaging succeeds. Model merging produces negligible gains (+0.0007 at best) because the trained students occupy different regions of parameter space — their weight vectors are not meaningfully interpolable. Score-level combination (soft routing) succeeds because it operates in the output space where the models' complementary strengths can be directly aggregated. This distinction has practical implications: soft routing requires maintaining multiple models at inference time, but the routing overhead (one cosine similarity lookup against cluster centroids) is negligible compared to the encoding cost.

All routing experiments use 30-epoch models from Set 1. Routing with 70-epoch models (Set 7) may yield different cluster assignments as methods converge further. Teacher embeddings for clustering are from the fine-tuned MiniLM-L6-v2 teacher.

This is a CS4248 NLP project repo for text-to-code generation and code search using the MBPP dataset. `MBPP_TUTORIAL.md` is the main guide covering both tasks end-to-end (fine-tuning with LoRA, evaluation with pass@k and MRR, model recommendations, and advanced techniques like DPO/RLEF). `ML_PIPELINE.md` is a prerequisite walkthrough of the 7-stage ML pipeline (data loading through saving). `assignment_details/PROJ_reqs.md` contains the original project requirements and dataset links.
